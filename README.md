# The Man in the Arena, mapped

A field map of Theodore Roosevelt's **"Citizenship in a Republic"** — the Sorbonne
address of 23 April 1910, from which the "man in the arena" paragraph comes.

**Live:** https://idvorkin-ai-tools.github.io/man-in-the-arena/

One static page per unit, dark, no build step, no JavaScript beyond a
localStorage progress ticker on the index.

## Text policy

The canonical text is the 1910 Scribner printing of _African and European
Addresses_ ([Project Gutenberg #13930](https://www.gutenberg.org/ebooks/13930)).
The widely-copied online versions differ from it in about ten small places;
those differences are listed on the close-reading page. No quotation on this
site is printed unless it was checked against a source, and any story about the
passage that the record does not settle is labelled as unsettled.

Roosevelt's speech is in the public domain. The explanations here are original
prose written for this map; they link to sources rather than reproducing them.
